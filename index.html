Langkah 9

Panduan Deploy

Ikuti langkah-langkah ini untuk menerbitkan laman web anda secara percuma menggunakan Cloudflare Pages.

1

Dapatkan Prompt dan Hasilkan Laman

Salin prompt yang dijana di Langkah 8 dan tampalkannya ke Claude (claude.ai). Claude akan menghasilkan satu fail index.html lengkap untuk laman web anda.

💡 Nota Gambar: Gambar profil, screenshot WhatsApp, dan gambar serahan yang dimuat naik akan disertakan terus dalam fail HTML (base64). Gambar model akan dipaut terus dari laman rasmi Perodua.

2

Simpan Fail index.html

Selepas Claude menghasilkan kod, klik butang "Salin" dan tampal ke dalam editor teks (Notepad, VS Code). Simpan sebagai index.html di folder komputer anda.

3

Buka GitHub dan Login

Buka github.com dan login ke akaun GitHub anda. Jika tiada akaun, daftar percuma di github.com/signup.

4

Cipta Repositori Baru

Klik butang "+" di sudut kanan atas → "New repository". Beri nama seperti laman-perodua-saya. Biarkan "Public". Klik "Create repository".

5

Upload Fail index.html

Di repositori baru, klik "Add file" → "Upload files". Seret fail index.html anda ke dalam kotak. Klik "Commit changes".

6

Buka Cloudflare Pages

Buka pages.cloudflare.com dan login (atau daftar percuma). Navigasi ke "Pages" dari menu sisi kiri.

7

Sambung ke GitHub

Klik "Create a project" → "Connect to Git". Pilih GitHub dan authorize jika perlu. Cari repositori laman-perodua-saya yang anda buat tadi.

8

Konfigurasi & Deploy

Dalam "Build settings", biarkan semua kosong (tiada framework). Klik "Save and Deploy". Cloudflare akan deploy laman web anda dalam beberapa minit.

9

Dapatkan URL Laman Web

Selepas deploy selesai, anda akan dapat URL seperti https://laman-perodua-saya.pages.dev. Kongsi URL ini dengan pelanggan! Anda juga boleh tetapkan domain sendiri di tab "Custom domains".

🎉 Tahniah! Laman web peribadi anda kini sudah siap dan boleh dikongsi dengan pelanggan.
